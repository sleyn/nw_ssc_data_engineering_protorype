# Test assignment for data science/engineering role

This is a test assignment for the data science/data engineering role.

# Structure

- `.scratch/description.txt` - the assignment text
- `data/data_v3` - data provided for the assignment
- `pre_eda/` - Rstudio project with manual EDA

# Conventions

- Use python as a main programming language
- Use `uv` for package management and venv
- Use mypy, ruff, pytest for CI
- Make the app HIPAA complaint:
  - Data encription
  - Authentification
  - Logging / Audit

# Goals

1. Generate final version of EDA analysis
2. Generate data QC report / tool
3. Make an interactive application for data exploration
